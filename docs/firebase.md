# فعال‌سازی پیام‌های پارسه

نسخهٔ پایه کاملاً آفلاین است و دسترسی اینترنت ندارد. ماژول اختیاری FCM فقط در صورت وجود `app/google-services.json` به ساخت اضافه می‌شود. برای فعال‌کردن آن:

1. در Firebase Console یک پروژهٔ متعلق به خودتان ایجاد کنید.
2. برنامهٔ Android با package name برابر `ir.parseh.poetry` ثبت کنید.
3. فایل تنظیمات `google-services.json` را در پوشهٔ `app` قرار دهید. این فایل عمداً در gitignore است.
4. برنامه را دوباره بسازید. گزینهٔ «دریافت پیام‌های پارسه» در تنظیمات ظاهر می‌شود.
5. کاربر باید خودش دریافت پیام و مجوز اعلان را فعال کند. دریافت خودکار توکن پیش از انتخاب کاربر غیرفعال است.

فایل service account یا کلید خصوصی را در اپلیکیشن یا مخزن قرار ندهید. پیام‌ها باید از محیط امن با Application Default Credentials و نقش مناسب Firebase Messaging فرستاده شوند.

```sh
python3 -m pip install google-auth requests
# پیش‌فرض فقط اعتبارسنجی است و پیام ارسال نمی‌شود:
python3 scripts/send_notification.py --project YOUR_PROJECT_ID --title 'پارسه' --body 'لحظه‌ای با شعر'
# ارسال واقعی به کاربران عضو موضوع:
python3 scripts/send_notification.py --project YOUR_PROJECT_ID --title 'پارسه' --body 'لحظه‌ای با شعر' --send
```

از پیام data-only با فیلدهای `title` و `body` استفاده می‌شود تا برنامه بتواند وضعیت انصراف کاربر را پیش از نمایش بررسی کند. در Android، تأخیر تحویل با مدیریت باتری، اتصال شبکه و Google Play Services وابسته است؛ تحویل آنی تضمین نمی‌شود. پس از force-stop برنامه نیز دریافت ممکن است تا اجرای دوباره متوقف شود. محتوای اعلان عمومی است و نباید اطلاعات خصوصی در موضوع همگانی ارسال شود.

راهکار حاضر و اسکریپت فرستنده هنوز با پروژهٔ واقعی Firebase آزموده نشده‌اند؛ صرف وجود سورس به معنی فعال‌بودن ارسال به کاربران نیست.
